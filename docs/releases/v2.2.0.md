# ADK UI v2.2.0

ADK UI 2.2 adds a complete surface lifecycle: render tools publish versioned surface references, agents can persist and mutate surfaces safely, and hosts can receive typed events and out-of-turn notifications.

## Surface lifecycle

- Every render tool records `adk_ui.active_surface` in `EventActions.state_delta`.
- `SurfaceStore` provides owner-scoped save, load, list, and delete operations with optimistic version checks.
- `InMemorySurfaceStore` supports tests and ephemeral agents; `FsSurfaceStore` uses sanitized paths and atomic file replacement.
- `UiToolset::with_persistence` installs the four persistence tools and gives `patch_surface` durable mutation semantics.

## Live data and charts

Charts, tables, and key-value components can bind to a JSON Pointer in the active data model. Manual, interval, and push refresh policies are supported while literal data remains the fallback. Charts add numeric/time axes, rolling windows, scatter plots, sparklines, labels, colors, and legend control.

## Events and notifications

`UiEventEnvelope` carries the originating surface revision and event metadata as typed ADK content. `UiNotificationChannel` lets background agent work publish notifications, which hosts can project to AG-UI through `notification_event`.

## Compatibility

Existing literal components and render-tool payloads remain valid. New application metadata fields use serde defaults, and persistence tools only appear when a store is configured.
