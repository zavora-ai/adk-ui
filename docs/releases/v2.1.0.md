# ADK UI v2.1.0

ADK UI 2.1 makes protocol capability discovery explicit and improves the quality of interfaces produced by agents. Hosts can now distinguish stable, candidate, partial, host-owned, planned, and legacy behavior instead of relying on a single compatibility label.

## Highlights

- **Versioned capability discovery:** `/api/ui/capabilities` exposes a 2026 schema with protocol versions, maturity, negotiation keys, content types, transports, fallbacks, and scoped claims.
- **A2UI:** v0.9.1 remains the stable surface target while the v1.0 correlated RPC subset is advertised separately as a release candidate.
- **AG-UI:** typed capability snapshots, lifecycle events, reasoning continuity, activity/state streams, and interrupt/resume wire models have explicit support boundaries.
- **MCP Apps:** the bridge targets the 2026-01-26 extension model with typed host capabilities, lifecycle notifications, and progressive fallback behavior.
- **Generated UI quality:** responsive KPI grids, stable component identity, safer nested layouts, persistent form state, and clearer empty/error states improve generated surfaces.
- **Rendering performance:** charts are lazy-loaded so applications that do not render charts avoid paying the Recharts cost in their initial renderer bundle.
